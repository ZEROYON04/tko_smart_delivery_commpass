# スマート配送コンパス in 広島 (Smart Delivery Compass)

## プロジェクト概要

「地域物流 2024年問題」を解決するためのプラットフォームです。
LINE連携、直前ステータス変更、相互リスペクトを組み合わせることで、広島県などの過疎地・中山間地域・坂道エリアにおける再配達の課題を解決します。

- 開発次第追加
