# スマ配 発表用デモストーリー

このデモの登場人物・住所・荷物番号はすべて架空です。地図上の座標には、東広島市内の公共施設周辺を使用しています。

## 登場人物

- 山田 一郎：配送ドライバー
- 佐藤 健太：最初の訪問先。LINE連携するデモの主役（お客様コード `USER-C`）
- 田中 美咲：佐藤さんの近隣にある、次の訪問先

対象の荷物IDは `00000000-0000-4000-8000-000000000103` です。

## 事前準備

1. `pnpm exec supabase db reset` でモックデータを初期状態へ戻す。
2. LINE公式アカウントへ `初回連携 USER-C` と送信する。
3. ドライバー画面を開き、佐藤さんが現在の配送先になっていることを確認する。

## 90秒デモ

### 1. 到着前の連絡

ドライバー画面の佐藤さんのカードで「LINEで到着通知」を押します。

説明例：

> 今までは、ドライバーが玄関へ着くまで、受取人の急な予定を知る方法がありませんでした。スマ配では、訪問前にあと何件・約何分かをLINEで通知します。

### 2. 10分不在で経路変更

LINEに届いた通知から「10分不在」を押します。ドライバー画面へ短時間不在がリアルタイム反映され、佐藤さんの訪問順が後ろへ移動し、田中さんなど別の荷物が先になります。

説明例：

> 佐藤さんは急用で10分だけ家を離れます。日付を変えるほどではありません。そこで10分不在を1タップで伝えると、その間に近くの荷物を先に届けるルートへ切り替わります。

### 3. 配達完了

田中さんの「配達完了」を押します。田中さんは「これから配達する荷物」から消え、下の「配達済み」へ移動します。地図と残りの経路も更新されます。

説明例：

> 配達完了後は一覧から自動で除外され、残りの荷物だけで次の経路を再計算します。

### 4. 不在時の再配達案内

別パターンとして「ご不在を記録」を押すと、受取人のLINEへ再配達日時を指定する案内が届きます。LINEのボタンから受取人画面を開き、一般的な配送時間枠で再配達日時を指定できます。

説明例：

> 短時間の不在で調整できなかった場合も、不在登録と同時に再配達日時の案内を送ります。受取人からの指定は、ドライバーのルートへ再び反映されます。

## 審査員へ伝える一文

> スマ配は日時指定を置き換えるものではありません。配達直前の「ほんの10分」という、既存の時間枠では扱えなかった予定変化を配送順へ反映し、再配達になる前にすれ違いを解消します。
